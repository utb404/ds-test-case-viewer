# Быстрый старт

## 🚀 Запуск проекта

### Вариант 1: Локальный запуск

#### 1. Запуск бэкенда
```bash
cd backend
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
pip install -r ../requirements.txt
python init_db.py  # Инициализация с примерами данных
python main.py
```

Бэкенд будет доступен по адресу: http://localhost:8000

#### 2. Запуск фронтенда
```bash
cd frontend
npm install
npm start
```

Фронтенд будет доступен по адресу: http://localhost:3000

### Вариант 2: Docker Compose

```bash
docker-compose up --build
```

### Вариант 3: Готовые скрипты

```bash
# Терминал 1 - Бэкенд
./run_backend.sh

# Терминал 2 - Фронтенд  
./run_frontend.sh
```

## 📋 Что вы увидите

После запуска откроется веб-интерфейс с:

## 🔧 API Endpoints

После запуска бэкенда доступны следующие endpoints:

- `GET /api/test-cases` - список тест-кейсов
- `GET /api/folders` - список папок
- `GET /api/search` - поиск с фильтрами
- `GET /api/export` - экспорт данных
- `POST /api/import` - импорт данных

Полная документация API доступна по адресу: http://localhost:8000/docs

## 🐛 Решение проблем

### Ошибка "Module not found"
```bash
# Убедитесь, что установлены все зависимости
pip install -r requirements.txt
npm install
```

### Ошибка подключения к API
```bash
# Проверьте, что бэкенд запущен на порту 8000
curl http://localhost:8000/api/test-cases
```

### Проблемы с базой данных
```bash
# Пересоздайте базу данных
rm backend/test_cases.db
python backend/init_db.py
```

## 🚀 Развертывание в продакшн

Для развертывания в продакшн рекомендуется:

1. **База данных**: PostgreSQL вместо SQLite
2. **Веб-сервер**: Nginx + Gunicorn
3. **Мониторинг**: Prometheus + Grafana
4. **Логирование**: ELK Stack
5. **Контейнеризация**: Docker + Kubernetes

Пример конфигурации для продакшн:
```bash
# Переменные окружения
export DATABASE_URL=postgresql://user:pass@localhost/test_cases
export SECRET_KEY=your-secret-key
export DEBUG=False

# Запуск с Gunicorn
gunicorn -w 4 -k uvicorn.workers.UvicornWorker main:app
```
